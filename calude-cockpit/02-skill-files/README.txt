Practice files for "Skill discovery" (lesson one, topic 2).
Everything here is fictional: Greenleaf Office Supplies is a made-up company.

Open this folder in VS Code, then follow the "Try it" steps on each skill card.

sales.csv                 12 months of sales: 3 products, 2 regions, with last year's numbers
customer-feedback.txt     15 customer comments from October
meeting-notes.txt         notes from the weekly team meeting
meeting-transcript.txt    word-for-word transcript of the same meeting
nda-draft.txt             an NDA draft from a supplier, with some one-sided clauses
supplier-price-list.pdf   a supplier's price list, as a PDF table
invoices/                 4 supplier invoices (PDF) with messy file names
raffle-entries.csv        customers in a giveaway (contains two duplicate rows)
messy-folder/             a messy folder with copies, old versions and random files
greenleaf-logo.png        the company logo

Tip: some skills create new files here. Keep a clean copy of this folder,
so you can start again whenever you want.
