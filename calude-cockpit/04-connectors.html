What is a connector?

A connector

A secure link between Claude and an app you use. You sign in, and Claude can read or act there. It works in chat, the desktop app and Claude Code.

Under the hood

An MCP server, usually run by the app's own company. It's the same technology as the tools on page 3. The difference: it opens your account, not just the web.

Think of it like this

A skill is know-how. A tool is a pair of hands. A connector is a key to one of your accounts.

How connectors reach Claude Code

Connect on claude.ai

On claude.ai, open Customize › Connectors. Find the app, click Connect, and sign in to it.

It appears in Claude Code

Claude Code brings in your connectors from claude.ai. Type /mcp to see them, named like "claude.ai Gmail". This works when Claude Code is logged in with your Claude account.

Team and Enterprise plans

Only admins can add connectors for the company. Ask your admin if the app you need is missing.

Google and Microsoft

Connect Gmail, Google Calendar, Drive and Microsoft 365 on claude.ai. Claude Code can't sign in to them by itself.

How to connect an app

1. On claude.ai

  1. Go to claude.ai/customize/connectors.
  2. Search for the app, for example Notion.
  3. Click Connect and sign in to the app.
  4. Read what Claude will be allowed to do, then approve.

2. Check in Claude Code

Start a new chat in VS Code and type /mcp. Look for "claude.ai" and the app's name. Missing? Type /status and check you're logged in with your Claude account.

3. Only in Claude Code

Type /mcp and add a server. Paste the address from the connector's card or directory page. Then choose it in /mcp and sign in. Not for Google or Microsoft.

How to use a connector

Name the app

Claude knows which connector to use when you name the app.

Use Notion to create a page with the action items from meeting-notes.txt.

Start with reading

Ask questions first: search, list, summarize. Move to actions later: send, post, create, pay.

Claude asks before acting

Before a connector changes something, Claude asks you. Read the request, then allow it or say no.

How to disconnect

Disconnect on claude.ai

Open Customize › Connectors, choose the app, and disconnect it. It disappears from Claude Code too.

Turn it off in one project

Type /mcp, choose the connector, and disable it. It stays connected everywhere else.

Remove access in the app

Most apps list connected services in their security settings. You can remove Claude's access from there too.

Good habit

Disconnect apps you don't use. Fewer keys means less risk.

Stay safe: a connector acts as you

Claude sees what you can see in that app, and can do what you can do.

"Verify you trust each server before connecting it. Servers that fetch external content can expose you to prompt injection risk."Claude Code documentation, MCP

Watch out for

  • Emails and documents with hidden instructions for AI.
  • Connecting an account with more access than the job needs.
  • Letting Claude send, post or pay without checking first.
  • Company data in apps your company did not approve.

5 good habits

  1. Connect only what you need for today's job.
  2. Read first, act later. Start with questions.
  3. Check every send, post and payment before you allow it.
  4. Use test modes, like Stripe's test mode.
  5. Disconnect what you don't use.

Work accounts

Ask before connecting work email or files.Some data must stay in approved systems.

Costs

Some apps charge for actions, like lead searches or videos.Check the app's pricing before big requests.

Try it yourself: connect, use, disconnect

About 15 minutes. Use the 04-connector-files folder and your Google account.

  1. Go to claude.ai/customize/connectors.
  2. Connect Google Calendar and sign in with your Google account.
  3. Open 04-connector-files in VS Code and start a new chat.
  4. Type /mcp. Do you see Google Calendar from claude.ai?
  5. Ask: Check my Google Calendar for next week. Suggest two free 30-minute slots for the follow-up meeting in meeting-notes.txt.
  6. Ask: Which of my meetings next week could be shorter? Don't change anything.
  7. Disconnect Google Calendar on the same claude.ai page.
  8. Start a new chat and type /mcp again. Is it gone?
Check yourself
In step 5 you get two real free times from your calendar. The follow-up meeting is on Monday, 9 November in meeting-notes.txt. In step 6 nothing changes in your calendar. Claude only suggests. After step 7, Google Calendar is gone from /mcp.

Summary

Connectors are keys to your apps: email, files, CRM, design and more. Connect on claude.ai, check with /mcp, and disconnect what you don't use. Start with reading, and check every action before you allow it.
