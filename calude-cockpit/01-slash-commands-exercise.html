Exercise: slash commands in VS Code

Ten short steps, about 30 minutes. You will use real commands on real practice files. Each step ends with a question, so you can check yourself.

You need

  • VS Code with the Claude Code extension, signed in.
  • The demo-folder from your instructor, saved on your computer.

If a command is missing

  • The VS Code panel has only some of the commands.
  • If a command is not in the / menu, use the button shown under it.
  • Claude's answers change a little each time. That is normal.
0 of 10 done
1

Open the practice folder

  1. Open VS Code.
  2. Click File > Open Folder and choose demo-folder.
  3. Update the Claude Code extension if VS Code offers it. Newer versions have more commands.
  4. Click ✻ Claude Code in the bar at the bottom of VS Code.
  5. Start a new conversation.

Can you see the three files on the left: feedback, sales and meeting notes?

2

Find any command in two seconds

/
  1. In the Claude Code box, type just /.
  2. Scroll the menu. These are all your commands.
  3. Now type /mo.

What happened to the menu when you typed /mo?

Check your answer
It shrinks to the matching commands, like /model. You never need to memorize commands.
3

Ask Claude about your customers

/context
  1. Ask Claude this question:
    Read customer-feedback.txt. What are the top 3 complaints?
  2. Then type /context to see how full Claude's memory is.
    Not in the menu? Look at the memory indicator in the prompt box.

What are the top 3 complaints?

Check your answer
1. Late deliveries (the most common, 6 customers). 2. Wrong items in the order. 3. Slow customer service replies.
4

Give your chat a name

/rename
  1. Type:
    /rename feedback-review
    Not in the menu? Open Session history at the top of the panel. Hover your chat and click Rename.
  2. Open Session history and find your chat.

Is your chat now called feedback-review?

Check your answer
Yes. Named chats are easy to find again in step 5.
5

Start fresh, then come back

/clear/resume
  1. Type /clear. This starts a brand-new chat.
    Not in the menu? Press Ctrl+Shift+P, type Claude Code, choose Open in New Tab.
  2. Ask:
    What were the top 3 complaints?
  3. Now type /resume and pick feedback-review.
    Not in the menu? Click Session history and pick feedback-review.
  4. Ask the same question again.

What was different between the two answers?

Check your answer
After /clear, Claude did not know. After /resume, it remembered everything. Clear for a new task, resume to continue an old one.
6

Try a different model

/model
  1. Type /model.
    Not in the menu? Click the model name at the bottom of the prompt box.
  2. Pick a different model from the list.
  3. Ask:
    Write a two-line thank-you to Yossi M. for praising our driver.
  4. Switch back to your first model when you are done.

Which model did you pick, and did the answer feel different?

Check your answer
Any answer is fine. Faster, cheaper models are great for small jobs like this one. Save the strongest model for hard work.
7

Make Claude plan before it acts

/plan
  1. Type:
    /plan Add a short section called "Top customer complaints" at the end of meeting-notes.txt, based on customer-feedback.txt.
    Not in the menu? Click the mode at the bottom of the prompt box and choose Plan. Then type the task.
  2. Read the plan. Nothing has changed yet.
  3. Approve the plan when Claude asks.
  4. Open meeting-notes.txt and scroll to the end.

When did the file actually change: before or after you approved?

Check your answer
Only after you approved. Plan first, act second. You stay the manager.
8

Undo it with rewind

/rewind
  1. Hover over your /plan message in the chat.
  2. Click the rewind button. Choose Rewind code to here.
    Or type /rewind and choose to restore the code.
  3. Open meeting-notes.txt again and scroll to the end.

Is the new section still there?

Check your answer
No. The file is back to the original. Rewind is a safety net, so you can experiment freely.
9

Turn numbers into a chart

/dataviz/btw
  1. Type:
    /dataviz Make a chart of monthly revenue for each product from sales.csv.
  2. Open the chart or the file Claude created.
  3. Quick side question, without cluttering the chat:
    /btw what does YoY mean?

What kind of chart did you get? Which product brings in the most money? Which grew the most since last year?

Check your answer
Usually a line or bar chart. Both are fine. Printer paper brings in the most money (about $172,000 in the year). Office chairs grew the most, about 22% more than last year. The best month was July 2026.
10

Take the answer with you

/copy
  1. Ask:
    Write a short email to the team with the top 3 complaints and one fix for each.
  2. Type /copy.
  3. Paste it into Notepad or a new email.

Did the full email paste in, ready to send?

Check your answer
Yes. One command takes Claude's answer straight into your email.

Well done. You used 10 commands today.
