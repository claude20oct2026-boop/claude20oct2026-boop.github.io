Why build your own tool?

Your rules, exactly

Price rules, delivery fees, stock levels, order numbers. Ready-made tools don't know how your business works. Your tool does, because you wrote the rules.

Exact answers, every time

Claude can slip on long sums and lookups. A tool runs your code, so the result is exact. Claude then explains it in plain words.

What we build here

A Greenleaf tool with 3 abilities: order_status looks up one order. late_orders lists late and delayed orders. delivery_fee works out the delivery cost.

Build it in Python, step by step

The finished tool is in the 03-05-tool-files folder. Read it, run it, then change it.

1. Install uv, once

uv is a small free program that runs Python for you. It downloads the right Python version by itself.

Windows (PowerShell)

powershell ‑ExecutionPolicy ByPass ‑c "irm https://astral.sh/uv/install.ps1 | iex"

Mac

curl ‑LsSf https://astral.sh/uv/install.sh | sh

Restart VS Code after installing, so it can find uv.

2. Open the practice folder

Open 03-05-tool-files in VS Code. Inside:

  • orders.csv: 20 Greenleaf orders, with status and promised date.
  • server.py: the tool itself, with 3 abilities.
  • .mcp.json: tells Claude Code how to start the tool.
  • .claude/skills/price-quote/: way 3, a skill with a script.

3. Read the code

server.py
"""Greenleaf tools: a small MCP server that lets Claude look up orders and delivery fees.

Fictional practice data for the Claude Code course.
Claude Code starts it for you (see .mcp.json). To start it by hand:
    uv run --python 3.12 --with "mcp[cli]>=2" mcp run server.py
"""
import csv
from pathlib import Path

from mcp.server import MCPServer
from mcp.server.mcpserver.exceptions import ToolError

# 1. Give the server a name. Claude Code shows it in /mcp.
mcp = MCPServer("greenleaf")

ORDERS_FILE = Path(__file__).parent / "orders.csv"
LATE = ("Delivered late", "Delayed")


def load_orders() -> list[dict]:
    """Read orders.csv. The tools below use this; it is not a tool itself."""
    with open(ORDERS_FILE, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


# 2. Each @mcp.tool() turns one Python function into one tool.
# 3. The docstring tells Claude what the tool does and when to use it.
# 4. The type hints (order_id: str) tell Claude what to send.
@mcp.tool()
def order_status(order_id: str) -> dict:
    """Look up one Greenleaf order by its number, like GL-1007.
    Returns the customer, items, total, status and promised delivery date."""
    wanted = order_id.strip().upper()
    for order in load_orders():
        if order["order_id"] == wanted:
            return order
    # 5. Raise ToolError for a problem Claude can fix. Claude reads the message and tries again.
    raise ToolError(f"There is no order {wanted}. Order numbers look like GL-1001.")


@mcp.tool()
def late_orders() -> list[dict]:
    """List all Greenleaf orders that are delayed or were delivered late."""
    return [order for order in load_orders() if order["status"] in LATE]


@mcp.tool()
def delivery_fee(order_total_usd: float, express: bool = False) -> dict:
    """Work out Greenleaf's delivery fee for an order.
    Standard delivery costs $8, and is free for orders of $300 or more.
    Express delivery adds $12."""
    if order_total_usd < 0:
        raise ToolError("The order total can't be negative.")
    fee = 0 if order_total_usd >= 300 else 8
    if express:
        fee += 12
    return {"order_total_usd": order_total_usd, "express": express, "delivery_fee_usd": fee}


# 6. Start the server when this file is run.
if __name__ == "__main__":
    mcp.run()
  1. A name for your server. You'll see it in /mcp.
  2. @mcp.tool() turns a normal function into a tool.
  3. The docstring is the tool's instructions for Claude.
  4. Type hints, like order_id: str, say what Claude must send.
  5. ToolError tells Claude what went wrong, so it can try again.
  6. mcp.run() starts the server and waits for Claude.

How to write a tool Claude uses well

Do

  • Give each tool a clear name, like order_status.
  • Write the docstring for Claude: what it does, and when to use it.
  • Keep inputs few and simple, with type hints.
  • Give each tool one job.
  • Start with tools that only read and calculate.
  • Raise ToolError with a helpful message.

Don't

  • Put passwords or keys in the code.
  • Return an error as normal text. Claude will think it worked.
  • Send back huge amounts of data. Return only what's needed.
  • Let a tool delete, send or pay without a check.

Keys and passwords

Keep them out of the code, in your computer's environment variables. Pass them to the tool in .mcp.json, then read them in Python:

.mcp.json (part)
"env": { "SHOP_API_KEY": "${SHOP_API_KEY}" }
server.py (part)
import os
api_key = os.environ["SHOP_API_KEY"]

The other way: a skill with a script

No server and no MCP. Just a folder with instructions and a script.

The instructions

Claude reads this file and knows when and how to run the script.

.claude/skills/price-quote/SKILL.md
---
name: price-quote
description: Makes a price quote for Greenleaf products, with bulk discounts. Use it when someone asks for a quote, an offer or a total price for several Greenleaf products.
---

# Greenleaf price quote

1. Find each product and its quantity in the request.
   Products: Office chair, Printer paper (box), Ink cartridge.
2. Run the script, with one "product=quantity" pair per product:

   uv run ${CLAUDE_SKILL_DIR}/quote.py "Office chair=12" "Printer paper (box)=60"

3. Show the script's table as it is. Never work out the prices yourself.
4. End with one friendly sentence the salesperson can send to the customer.

The script

Plain Python that does the math, so prices are always right.

.claude/skills/price-quote/quote.py
"""Greenleaf price quote. Usage: uv run quote.py "Office chair=12" "Printer paper (box)=60"
Fictional prices for the Claude Code course. Uses only built-in Python, nothing to install."""
import sys

PRICES = {"Office chair": 189.00, "Printer paper (box)": 32.00, "Ink cartridge": 45.00}
BULK = {"Office chair": (10, 0.10), "Printer paper (box)": (50, 0.15)}  # (minimum quantity, discount)

total = 0.0
print(f"{'Product':<22}{'Qty':>5}{'Price':>10}{'Discount':>10}{'Line total':>12}")
for arg in sys.argv[1:]:
    name, _, qty = arg.partition("=")
    name = name.strip()
    if name not in PRICES or not qty.strip().isdigit():
        sys.exit(f"Can't read '{arg}'. Use names from this list: {', '.join(PRICES)}")
    qty = int(qty)
    minimum, rate = BULK.get(name, (0, 0.0))
    discount = rate if minimum and qty >= minimum else 0.0
    line = qty * PRICES[name] * (1 - discount)
    total += line
    print(f"{name:<22}{qty:>5}{PRICES[name]:>10.2f}{discount:>10.0%}{line:>12.2f}")
print(f"{'Total (USD)':<57}{total:>12.2f}")

The same tool in TypeScript

For people who build web apps. Not needed for the exercise.

1. Install

In a new folder, with Node.js installed:

npm install @modelcontextprotocol/server zod

2. Write the tool

server.mjs
import { McpServer } from '@modelcontextprotocol/server';
import { StdioServerTransport } from '@modelcontextprotocol/server/stdio';
import * as z from 'zod/v4';

const server = new McpServer({ name: 'greenleaf-ts', version: '1.0.0' });

server.registerTool(
  'delivery_fee',
  {
    description: "Work out Greenleaf's delivery fee. Standard costs $8, free from $300. Express adds $12.",
    inputSchema: z.object({ order_total_usd: z.number(), express: z.boolean().default(false) })
  },
  async ({ order_total_usd, express }) => {
    const fee = (order_total_usd >= 300 ? 0 : 8) + (express ? 12 : 0);
    return { content: [{ type: 'text', text: `Delivery fee: $${fee}` }] };
  }
);

await server.connect(new StdioServerTransport());

3. Connect it

Same .mcp.json idea, with a different start command:

.mcp.json
{
  "mcpServers": {
    "greenleaf-ts": { "type": "stdio", "command": "node", "args": ["server.mjs"] }
  }
}

Share your tool

In a shared folder

Keep server.py and .mcp.json in the project folder. Teammates open the folder and approve the server. Teams usually share project folders through Git.

In the Claude desktop app

One command adds your tool to the desktop app:

uv run ‑‑python 3.12 ‑‑with "mcp[cli]>=2" mcp install server.py

Then fully quit the desktop app and open it again.

As a plugin

A plugin can hold your tool, skills and commands together. Teammates install everything with one command.

Online, as a connector

The same server can run on the internet, over HTTP:

uv run ‑‑python 3.12 ‑‑with "mcp[cli]>=2" mcp run server.py ‑‑transport streamable‑http

Host it, then add its address on claude.ai as a custom connector. This needs hosting and sign-in. Ask a developer to help.

Stay safe

Remember

  • Your tool runs on your computer, with your permissions.
  • A tool can read any file your code points it to.
  • Approve only servers you wrote or trust.

Good habits

  • Start read-only: look up and calculate first.
  • Test with practice data, never real customer files.
  • Keep the permission prompt on until you trust the tool.
