What is a skill?

A skill

A folder with instructions for Claude. It teaches Claude one job, your way. Claude uses it when it fits. Or type /skill-name to start it.

A plugin

A package of several skills. It can also add tools and connections. Most skills come inside a plugin.

Think of it like this

Claude is a smart new employee. A skill is the manual for one task. A plugin is a whole training course.

How to install a skill

Three ways. Pick the one that matches where the skill comes from.

1. In VS Code

  1. In the Claude Code box, type /plugins.
  2. For Anthropic's skills, open the Marketplaces tab and add anthropics/skills.
  3. Open the Plugins tab and search for the plugin.
  4. Click Install, then choose Install for you.

Plugins tab empty? Add anthropics/claude-plugins-official on the Marketplaces tab.

2. In the terminal

Anthropic's skills

/plugin marketplace add anthropics/skills /plugin install document-skills@anthropic-agent-skills /plugin install example-skills@anthropic-agent-skills

The official marketplace

/plugin install playground@claude-plugins-official

Or type /plugin alone and browse the Discover tab.

3. Copy a skill folder

Use this for skills from GitHub that are not plugins. Copy the skill's folder into one of these places:

Just for you, in all your projects

C:\Users\<you>\.claude\skills\

For this project only

.claude\skills\ inside your project folder

Claude picks it up without a restart.

Or use the skills.sh installer, in a terminal (needs Node.js)

npx skills add owner/repo --skill skill-name -a claude-code --copy -y

Did it work?

Type / and look for the skill's name in the menu. Or type /skills to see your full list.

How to use a skill

Just ask

Claude picks the right skill by itself. Naming the skill makes it even more reliable:

Use the xlsx skill to turn sales.csv into an Excel file.

Type its name

Start your message with a slash and the skill's name, then your request.

/internal-comms write a status update from meeting-notes.txt

Skills inside a plugin

They show as /plugin-name:skill-name. Type / and the plugin's name to find them.

How to remove or turn off a skill

Remove a plugin

VS Code: type /plugins, find the plugin, and uninstall it. Terminal:

/plugin uninstall example-skills@anthropic-agent-skills

Turn it off for now

Keep it installed, but stop it from running. VS Code: type /skills and change the skill's visibility. Terminal: type /plugin disable and choose the plugin.

Remove a copied skill

Delete its folder from your skills folder. It disappears from /skills right away.

Good habit

Remove skills you do not use. Fewer skills means less risk and lower cost.

How to share skills with your team

Share a project folder

Put the skill in .claude\skills\ inside the project folder. Everyone who opens that project gets the skill too. Teams usually share project folders through Git.

Share a plugin

Install it with Install for this project. Claude saves that choice in the project's settings. Each teammate then installs it once on their own computer.

On claude.ai

Upload a skill as a ZIP file under Customize > Skills. Team and Enterprise plans can share skills with colleagues. Admins can publish skills to the whole company.

Stay safe: skills can run code on your computer

Most skills are just instructions. Some also include programs. Treat them like any software you download.

"A Claude Code plugin you install can execute arbitrary code on your machine with your user privileges."Claude Code documentation, plugin security
"Make sure you trust a plugin before installing, updating, or using it."Anthropic's official plugin marketplace

Skills to avoid

  • An unknown author, with no history and no other users.
  • It asks you to paste a password or API key.
  • It includes programs or scripts you cannot read or understand.
  • It sends your files or data to outside websites.
  • It can spend money, send emails or sign things without asking you.
  • A copy of a famous skill under a slightly different name.

Before you install: 5 checks

  1. Who made it? Anthropic, a known company, or a stranger?
  2. Read SKILL.md. Does it do only what it says?
  3. Look for programs. Check folders like scripts and bin.
  4. Check the audits. skills.sh shows security scan results.
  5. Test it first. Use a practice folder, not real client files.

Updates can change it

A plugin you checked today can change after an update.Re-check skills that touch money or customer data.

Connected accounts

Some skills connect to Canva, Spotify or shipping accounts.They can act in that account for you.

At work

Ask IT before installing skills on a work computer.Companies can block or approve plugins for everyone.

Try it yourself: install, use, remove

About 15 minutes. Use the demo-folder from the slash commands exercise.

  1. Open demo-folder in VS Code and open Claude Code.
  2. Type /plugins. On the Marketplaces tab, add anthropics/skills.
  3. On the Plugins tab, find example-skills. Install it for you.
  4. Type / and look for algorithmic-art.
  5. Ask: Use the algorithmic-art skill to make generative art inspired by sales.csv. Open the file it creates in your browser.
  6. Ask: Use the internal-comms skill to write a short status update from meeting-notes.txt.
  7. Remove it: open /plugins and uninstall example-skills.
  8. Type / again. Is algorithmic-art gone?

Working in the terminal instead?

/plugin marketplace add anthropics/skills /plugin install example-skills@anthropic-agent-skills /plugin uninstall example-skills@anthropic-agent-skills
Check yourself
Step 5 gives you an HTML page with moving, colorful art. Step 6 gives you a clear update about deliveries, wrong items and slow replies. After step 7, the skill is gone from the / menu.

Summary

Skills are training manuals that give Claude new jobs. Find them, read them, install them, and remove what you don't use. Trust official sources first, and check everything else.
