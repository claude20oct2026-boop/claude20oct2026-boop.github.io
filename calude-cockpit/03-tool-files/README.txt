Practice files for "Tools" (lesson one, topic 3).
Everything here is fictional: Greenleaf Office Supplies is a made-up company.

Open this folder in VS Code, then follow the steps on each tool card.

customer-feedback.txt   15 customer comments from October
meeting-notes.txt       notes from the weekly team meeting, with action items
sales.csv               12 months of sales: 3 products, 2 regions
faq.txt                 answers to common customer questions (for the phone receptionist example)
site/index.html         a small one-page website for Greenleaf (for the publishing example)

Tip: some tools create new files here. Keep a clean copy of this folder,
so you can start again whenever you want.
