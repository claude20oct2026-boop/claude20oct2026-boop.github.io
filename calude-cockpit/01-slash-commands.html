Slash commands: the control panel of Claude Code

A teaching guide for you, the instructor. For every command: what it does, why a business person cares, how to demo it live, and a sentence you can say out loud to beginners.

1. The big idea (teach this first)

A prompt vs. a command

A prompt is what you ask Claude to do ("summarize this report"). A slash command is what you tell the tool itself ("start over", "show me the cost", "switch model"). Anything starting with / is for the tool.

"Prompts talk to Claude. Slash commands talk to the app. Think of the buttons on a remote control."

What is a token?

Claude reads and writes in small pieces of text called tokens (roughly ¾ of a word in English). Tokens are what you pay for and what limits how much Claude can hold in its head at once.

"Tokens are the fuel. Longer conversation, more fuel burned, higher bill."

What is "context"?

The context window is Claude's working memory for this conversation: your messages, files it read, its own answers. When it fills up, quality drops and cost grows.

"Context is the size of Claude's desk. A cluttered desk means slower and sloppier work."

The one trick that makes everything easy

Type just / in Claude Code and a menu of every command appears. Keep typing letters to filter it, use the arrow keys, press Enter. Nobody has to memorize anything. Show this in the first two minutes.

2. Suggested flow for the class

Total of about 45 to 60 minutes for this topic. Shrink or stretch the middle sections to fit your slot. Beginners should leave remembering about 8 commands, not 30.

  1. Show the menu (3 min). Type /, scroll, filter with /mo. "You never need to memorize."
  2. Tier 1: Survival kit (20 min). /help, /clear, /context, /usage, /compact, /model, /resume. Do these live, all of them.
  3. Tier 2: Work smarter (10 min). Pick 3: /init, /plan, /rewind. Mention the rest.
  4. Tier 3: Control and safety (5 min). /permissions is the one managers care about.
  5. Tier 4: Business power commands (10 min). Pick 1 or 2 for a wow moment: /deep-research, /slides, /loop.
  6. Tier 5: Teaser (2 min). /skills, /plugin, /mcp are the next topics in this lesson.
  7. Mini exercise (10 min). See section 5.

3. The commands

Each card has: What it does, Business angle, Demo (steps you do yourself), and Summary. Commands that keep running also get How to stop it.

Claude Code itself needs a paid plan (Pro, Max, Ultra, Team or Enterprise) or an API account. A yellow tag next to a command means it needs something extra.

Before the demos: get the practice files

  • The demos use a folder called demo-folder, from your instructor.
  • It holds three practice files about a made-up office-supplies company.
  • customer-feedback.txt: 15 customer comments from October.
  • sales.csv: monthly sales for three products, with last year's numbers.
  • meeting-notes.txt: notes from the company's weekly team meeting.
  • Save the folder on your computer, then open Claude Code inside it.

4. Developer commands you can safely skip

These appear in the menu and students will ask. A one-line answer is enough: "That one is for software developers reviewing code."

/code-review (alias /review), /security-review, /simplify, /diff, /batch, /install-github-app, /ide, /terminal-setup, /vim (removed in newer versions), /sandbox, /hooks.

Exception: if your students are technical, /code-review and /security-review make a nice bonus.

5. Mini exercise for students (10 minutes)

"Run a small job, then manage it like a pro." Each student does the steps in order:

  1. Open Claude Code in the demo folder. Type / and find three commands they like.
  2. Ask Claude: "Read customer-feedback.txt and give me the top 3 complaints."
  3. Run /context. Write down how many tokens were used.
  4. Run /usage. Write down what it says about cost or limits.
  5. Run /rename feedback-analysis, then /clear, then /resume and get the old work back.
  6. Run /model and look at the options. Discuss: when would you pick the cheaper, faster one?

Debrief question: "If you gave this tool to ten employees, which three commands would you want every one of them to know, and why?"
