What is a tool?

A tool

An action Claude can take. Read a file, search the web, click a button. Claude picks the right tool for each step.

An MCP server

A package of tools from another company. MCP is a standard plug for AI tools. Most arrive inside a plugin, ready to use.

Skill, tool or connector?

A skill is know-how: how to do a job. A tool is hands: something Claude can do. A connector is a key to your accounts.

How to add a tool

Three ways. The first one is the easiest.

1. As a plugin

  1. In the Claude Code box, type /plugins.
  2. Search for the tool on the Plugins tab.
  3. Click Install, then choose Install for you.
  4. If it needs an account, type /mcp, choose it, and sign in.

In the terminal

/plugin install playwright@claude-plugins-official

2. From the /mcp menu

Type /mcp in the VS Code panel and add a server. Paste the tool's address, from its directory page or website. Then choose it in /mcp and sign in, if it asks.

3. In the terminal

For people who use the Claude Code command line:

claude mcp add --transport http notion https://mcp.notion.com/mcp

The VS Code panel and the terminal share the same list of tools.

Did it work?

Start a new chat and type /mcp. Your tool should say Connected. It says it needs sign-in? Choose it and sign in.

How to use a tool

Just ask

Claude picks the right tool by itself. Naming the tool makes it more reliable:

Use Playwright to open wikipedia.org and take a screenshot.

Your own browser

With Claude in Chrome, start your request with @browser.

@browser open my Gmail and count today's unread emails.

Approve each action

Claude asks before a tool changes something. Read the request, then allow it or say no.

How to remove or turn off a tool

Remove a plugin

VS Code: type /plugins, find the plugin, and uninstall it. Terminal:

/plugin uninstall playwright@claude-plugins-official

Turn it off for now

Type /mcp, choose the tool, and disable it. It stays installed, but Claude can't use it.

Remove a server you added

Remove it in the /mcp menu, or in the terminal:

claude mcp remove notion

Good habit

Remove tools you don't use. Each one adds risk and cost.

Stay safe: tools can act for you

A tool can click, publish, send and buy. Treat it like a new employee.

"Verify you trust each server before connecting it. Servers that fetch external content can expose you to prompt injection risk."Claude Code documentation, MCP
"A Claude Code plugin you install can execute arbitrary code on your machine with your user privileges."Claude Code documentation, plugin security

Watch out for

  • Web pages with hidden instructions for AI. This is called prompt injection.
  • A tool that asks you to paste a password or key into the chat.
  • Tools that publish, send or pay without asking you first.
  • An unknown author, with no users and no history.
  • A copy of a famous tool under a slightly different name.

Before you add a tool: 5 checks

  1. Who made it? Anthropic, the tool's company, or a stranger?
  2. What can it do? Read its list of tools in /mcp.
  3. Which account? Try it with a test account first.
  4. Keep approvals on. Let Claude ask before each action.
  5. Practice first. Use practice files, not real client data.

Your browser is signed in

@browser uses your real Chrome, with your logins.Claude can see what those websites show you.

Published means public

Anyone with the link can open a site or app you publish.Never publish customer data or private numbers.

At work

Ask IT before adding tools on a work computer.Companies can allow or block tools for everyone.

  3. Start a new chat and type /mcp. Does playwright say Connected?

Summary

Tools are Claude's hands: browsers, search, publishing and more. Add them as plugins, check them in /mcp, and remove what you don't use. Trust reviewed sources first, and keep approvals on.
